这是怎么在浏览器里跑的？

没有后端接口：playground.wasm 与页面一起被静态托管，你点击的每一次计算都只发生在自己的设备上。

  1. playground/ 是一个 pkgtype(kind: "foreign_library") 的 MoonBit 包，用 #export_name 导出 f64 → f64 包装函数。
  2. moon build --target wasm-gc --release playground 生成 playground.wasm（约 12 KB，无任何 import）。
  3. 页面 fetch 该 wasm 并 WebAssembly.instantiate，直接调用导出函数；数值算法（gamma、Bessel、erf、KDE）都来自 owl-mbt 的纯 MoonBit 实现。
  4. CI 在工作流中重新构建 wasm 并部署到 GitHub Pages，保证页面与源码同步。

WasmGC 需要较新的浏览器（Chrome 119+ / Firefox 120+ / Safari 18+）。计算结果与 native 后端一致（同一份 MoonBit 源码）。
