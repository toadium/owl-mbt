# 审查范围界定

## 审查目标
Owl 科学计算库 OCaml → MoonBit 移植项目的全面代码审查。

## 审查依据
两者结合：MoonBit 风格规范 + 通用 API 设计原则
- MoonBit 风格：`///|` 分隔符、命名约定（lower_snake / UpperCamel）、`pub` 可见性、文件组织、错误处理（`raise`/`suberror`）、`Ref[T]` 使用、箭头函数
- 通用 API 设计：接口最小化、一致性、可组合性、忠实移植行为、文档完备性、测试覆盖充分性

## 审查重点维度（全部）
1. **正确性**：算法实现是否正确，是否忠实于 Owl 源码行为
2. **安全性**：边界条件、错误处理、数组越界、数值稳定性
3. **性能**：不必要的分配、循环效率、缓存友好性
4. **可维护性**：代码组织、命名清晰度、文件结构、模块边界
5. **API 设计**：公共接口最小化、一致性、文档完备
6. **MoonBit 惯用法**：`///|` 分隔、`pub` vs `pub(all)`、`raise` 效果系统、`Ref[T]` 可变性、箭头函数、模式匹配
7. **测试质量**：边界用例、数值精度、互逆关系验证、业务场景覆盖

## 排除范围
全面审查，不排除任何内容。
